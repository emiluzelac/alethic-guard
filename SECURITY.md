# Security

The production support scope covers explicitly enrolled guests on the Ubuntu 24.04 x86-64 KVM configurations listed in the [guarantee matrix](docs/GUARANTEE_MATRIX.md). Review the [threat model](docs/THREAT_MODEL.md) before introducing sensitive inputs.

Report suspected vulnerabilities through [GitHub's private vulnerability reporting form](https://github.com/emiluzelac/alethic-guard/security/advisories/new). Include the affected release or commit, runtime versions, the expected boundary, and the behavior you observed with synthetic inputs. Redact host credentials, collector keys, and private data.
