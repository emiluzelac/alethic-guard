# Security

Treat this project as a lab preview. Scope the host boundary to explicitly enrolled guests on the measured configuration in [the guarantee matrix](docs/GUARANTEE_MATRIX.md). Review the [threat model](docs/THREAT_MODEL.md) before introducing sensitive inputs.

Use a private channel with the repository maintainer to report suspected vulnerabilities. Include the affected commit, runtime versions, and a synthetic description of the boundary failure. Keep sensitive inputs, host credentials, and collector keys out of reports.
