The first public lab preview of Alethic Guard qualifies two profiles on the measured Ubuntu 24.04.5 x86-64 nested KVM configuration.

- `offline-strict` enrolls a NIC-free guest with a private overlay and optional approved read-only input.
- `allowlisted-api` adds a host-governed synthetic `public-demo` operation to an exact IPv6 HTTPS collector endpoint. Its controller uses the published `alethic-kernel==0.4.0` wheel.

The Linux archive includes the host daemon, gateway, CLI/controller wheel, policy examples, systemd unit, deployment instructions, and lab fixtures. Verify the archive against `SHA256SUMS`.
