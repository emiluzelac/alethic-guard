# Alethic Guard v0.2.0

Linux x86-64 lab preview for the qualified Ubuntu/KVM configuration. This release includes the HTTPS release evidence collector, a sample policy, and a guest client.

- [Download the archive](alethic-guard-0.2.0-linux-x86_64.tar.gz)
- [SHA-256 checksum](SHA256SUMS)
- [Installation guide](https://github.com/emiluzelac/alethic-guard/blob/v0.2.0/docs/DEPLOY_LINUX.md)
- [Tested configurations](https://github.com/emiluzelac/alethic-guard/blob/v0.2.0/docs/GUARANTEE_MATRIX.md)

Save the archive and `SHA256SUMS` in the same directory and run `sha256sum -c SHA256SUMS` before unpacking.
